Some of the most significant challenges for a new learner I would say would be getting familiar with coding and how it is done, it uses its own language and once you get the hang of that you will be good to go. It takes a lot of practice, time and determination. For me I did a coding class at Erie Institute Of Technology. I really struggled with it there but it’s like riding the back. Once you get back into things you begin to remember and recognize terms and shortcuts. I would recommend to someone brand new trying to learn this material to not doubt yourself, become confident and really take a couple hours and sit down and try to learn it. That is exactly what I did and it really helped me.

An advantage I would say would be Wordpress. Learning that is much easier than learning HTML and CSS in my opinion. Yeah you need to have coding to paste into wordpress but it is a lot more customizable. You can go in and make edits and changes. It is a lot more user friendly in my opinion and I actually like that one more. I would say the challenges for modifying the layout and organizing each site would be in the code, what I mean by that is making sure everything is organized and in layers. Similar to how you talked about it in class with a tree branch, everything is connected and you have to make sure you are staying organized section by section. For Wordpress the only challenges that I am facing are deciding what layout I want to use on my site. It’s very customizable and I enjoy using it so sometimes I can spend more time than I need to on things because of how customizable it is.

I would say the skills that are necessary for this are definitely to be organized. Being organized in this will make your life so much easier. Other forms of skills are a basic understanding of how to code and the shortcuts. Some skills that I would like to learn and to help improve my website would be how to improve the layout. Another one would be to become more comfortable with change in colors and fonts as well as being more comfortable in image sizing.
